Notes on what the tests saw:

1. **The theme is kept in the browser.** The choice is stored in the browser, so it survives a reload on the same browser, as criterion 1.1 asks. Nothing here checks it on another browser or device, and the dashboard does not say it should follow the teammate there.
2. **The store switcher's picture.** The screenshot was taken once Winkel's dashboard had opened, while its figures were still loading. Its currency menu already shows euros, Winkel's own currency.
3. **The release notes.** With the newer release answered, the dashboard asks GitHub for that release's notes. The test blocks the request, so the dialog says "The release notes could not be loaded. Read them on GitHub instead." beneath the release. Part 2 captured the notes themselves by storing them in the browser first; P6 asserts only what criterion 1.3 asks.
4. **The settings search on Taxes.** Choosing Taxes opens its first page, the tax categories.

## 3. What this does not show

- **Spree's real update service (G-20).** Test 3 answers the update check in the browser, as the owner accepted for G-20. It shows how the dashboard presents a newer release, not that Spree's server finds one. Test 4 shows the server's answer in the test environment, where the check is switched off.
- **The server's validation of the profile dialog (G-21).** Not part of P6, and not verified.
- **Refused requests (G-11, with G-23).** Every test signs in as the admin, who may do everything. What the palette's searches refuse to a role that may not read the record stays in G-11.
- **Tenant isolation.** Test 2 shows the switcher opening a second store the admin holds a role on. It does not show that a store's data stays out of another store's dashboard. That stays FB-03's validation, NOT_RUN.

**Whether anything else keeps CAP-04-05 PARTIAL.** Yes. If the owner accepts this record and closes G-22, every behaviour in CAP-04-05 has a browser test that passes. G-23's refused palette searches, which the owner linked to G-11, still keep it PARTIAL, as G-11 keeps CAP-04-03 and CAP-04-04. G-20 and G-21 are limits the owner accepted, and this record does not count them against it.

## 4. Defects found

None. No test failed in a recorded run. While the tests were written, two of them needed corrections before the recorded runs, both in the tests themselves. The settings search first counted the rail's "Back to dashboard" link as a settings page. The theme test first read the page's background while its colour transition was still running; it then waited for every animation on the page, which never happens because the page always has one running, and now waits for the background's own transition only.
