# FB-19 batch 9, storefront cart and checkout, reference images for review

This list holds every reference image batch 9 commits, by inventory ID ([LIQ-009](../LIQ-009-spree-component-and-token-inventory.md)), so that each can be accepted or rejected. On 2026-11-04 batch 9 was accepted by delegated acceptance, under the owner's delegation of 2026-11-04, by Claude ([verification record §15](2026-11-04-fb-19-batch-storefront-cart-and-checkout.md#15-delegated-acceptance)). The owner did not review these images. The Acceptance column reads DELEGATED ACCEPTANCE for each image, because that acceptance covers every image in the list.

**What to look at.** Each link opens the image as committed in storefront pull request [#24](https://github.com/pateldhruval872/liquorify-storefront/pull/24), at `8ce4a18`, which holds all of them; the pull request's file list shows the same images. Every image was looked at before it was committed. Stories use invented products, addresses, codes and amounts; the running screens show Spree's sample catalog with what the capture scripts add. The cart drawer's stories are captured at the window's size, 390 or 1280 by 844 pixels; the rest at the size of what they draw, which for a checkout page is its whole length. Each story is drawn in the storefront's one theme.

**What the Running screen column means.**
- **Compared:** the story was put beside the same component on the running storefront, and the result is in the [verification record](2026-11-04-fb-19-batch-storefront-cart-and-checkout.md) §4. "Compared within" means it was compared as part of a larger component that holds it. Images and computed styles are in the [evidence index](evidence/2026-11-04-fb-19-batch-storefront-cart-and-checkout/README.md). The comparison is diagnostic: it informs the review and does not replace it.
- **Seen in a capture:** the state appears in a running-screen capture, linked here at 1280 pixels unless the row says 390, but the script did not put the story beside it.
- **Not compared; checked against its source:** no running screen showed that state, so it was checked against the component's source only, for the reason given. The stories marked mocked draw a payment provider's form through a labelled stand-in for its library; they are G-76, and real-provider verification stays open (record §5). The others are G-73 (record §11).

**How a decision is recorded.** An image is accepted or rejected in the pull request, row by row or as a whole. An image rejected is fixed in its story, its fixtures or its mocks, never by changing the component ([LIQ-010 §12.1](../LIQ-010-design-system-reproduction-architecture.md#121-each-batch)).

**Counts.** 81 stories, 162 images. 27 compared on a running screen, 1 of them within another component; 17 seen in a capture; 20 checked against their source only; and 17 mocked, checked against their source and the stand-ins.
