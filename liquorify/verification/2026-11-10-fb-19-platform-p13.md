### 1.2 Changes during the development trials

No expected result, refusal or control was corrected. Part B's answers were all as written from the first trial. In part A, these changes were made to how a test sets up or reads the screen. None of them changes what the test expects.

- **The placed orders read `placed`.** The seed first expected an order's status to read `complete`. Spree's status for a placed order is `placed`, so the seed's own check was corrected.
- **A.4 sends the refused number first.** A customer may hold one EU VAT registration. The trial added a valid number, then tried the refused number, and the server refused it as "has already been taken" instead of for its format. The test now tries the refused number first.
- **A.9's refused row has no email.** The trial's refused row had an email with no `@`, and the wizard imported it. The test now refuses a row with no email, which Spree refuses. The accepted email is recorded as SD-95 (§3.2).
- **A.10 picks "All records" by its exact name.** A second option also contains the words.
- **A.11 reads the field's error message.** The message under the Email field reads "has already been taken", with the field's label, Email, beside it. The test matches the message with or without the word "Email".
- **A.12 waits for the list's rows** before counting them.
