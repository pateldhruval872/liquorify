**What the Running screen column means.**
- **Compared:** the story was put beside the same component on Spree's running admin dashboard, and the result is in the [verification record](2026-11-04-fb-19-batch-inventory.md) §4. Images and computed styles are in the [evidence index](evidence/2026-11-04-fb-19-batch-inventory/README.md). The comparison is diagnostic: it informs the review and does not decide it.
- **Seen in a capture:** the state appears in a running-screen capture, linked here, but the script did not put the story beside it. A capture of a role other than the admin names the role.
- **Not compared; checked against its source:** no running screen showed that state with the browser-test data, or the script could not reach it there, so it was checked against the component's source only. Where a reason is known, it is given. These stories are G-85 (record §7).

**How a decision is recorded.** An image is accepted or rejected in the pull request, row by row or as a whole. An image rejected is fixed in its story, its providers or its mocks, never by changing the component ([LIQ-010 §12.1](../LIQ-010-design-system-reproduction-architecture.md#121-each-batch)).
