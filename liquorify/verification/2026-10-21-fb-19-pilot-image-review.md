# FB-19 pilot reference images for the owner's review

This list holds every reference image the pilot commits, by inventory ID ([LIQ-009](../LIQ-009-spree-component-and-token-inventory.md)), so the owner could accept or reject each one. The owner accepted every image on 2026-10-21, within the pilot's scope ([acceptance record](2026-10-21-fb-19-pilot-merge-and-acceptance.md)). A row whose story was checked against its source only keeps that comparison open: its image is accepted, but no running screen has shown its state yet.

**What to look at.** Each link opens the image at the pilot's final revision: backend `d0898ad` in [#6](https://github.com/pateldhruval872/liquorify/pull/6), storefront `d84dc61` in [storefront #15](https://github.com/pateldhruval872/liquorify-storefront/pull/15). The pull requests show the same images in their file lists.

**What the Running screen column means.**
- **Compared:** the story was put beside the same component on Spree's running admin dashboard, seller panel or storefront, and the result is in the [fidelity record](2026-10-21-fb-19-pilot-fidelity.md) §3. The images were looked at side by side and their computed styles compared; both are published in the [evidence folder](evidence/2026-10-21-fb-19-pilot-fidelity/README.md). That comparison is diagnostic, so it informs the owner's review and does not replace it.
- **Token values compared:** every token value on the token page was compared with the running screens' tokens.
- **Not compared; checked against its source:** no running screen showed that state with the browser-test data, so it was checked against the component's source only ([fidelity record](2026-10-21-fb-19-pilot-fidelity.md) §4).

**How the decision was recorded.** The owner accepted the pilot as a whole on 2026-10-21, after both pull requests merged, rather than row by row; the [acceptance record](2026-10-21-fb-19-pilot-merge-and-acceptance.md) says what it covers and what stays open. An image rejected later is fixed in its story, its providers or its mocks, never by changing the component ([LIQ-010 §12.1](../LIQ-010-design-system-reproduction-architecture.md#121-each-batch)).

**Counts.** Backend: 41 stories, 82 images. Storefront: 20 stories, 38 images. Of the 61 stories, 18 were compared on a running screen, 8 token pages had their values compared, and 35 were checked against their source only.
