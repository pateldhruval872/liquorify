# FB-19 catalog and pricing batch, part 2, reference images for review

This list holds every reference image part 2 commits, by inventory ID ([LIQ-009](../LIQ-009-spree-component-and-token-inventory.md)), so each can be accepted or rejected. Since 2026-11-04 the routine image and fidelity acceptance of approved baseline work is delegated by the owner (recorded in [#39](https://github.com/pateldhruval872/liquorify/pull/39), not yet merged); an acceptance made under it is recorded here as delegated acceptance, never as the owner's review.

**What to look at.** Each link opens the image beside this list, in the revision being read, and the pull request's file list shows the same images. Every image was looked at in light and dark before it was committed. Stories use invented products, categories, prices and files; the running screens show the browser tests' data and Spree's sample catalog. Some story names hold a comma of their own, such as "Dialog, no filter".

**What the Running screen column means.**
- **Compared:** the story was put beside the same component on Spree's running admin dashboard, and the result is in the [verification record](2026-11-04-fb-19-batch-catalog-and-pricing-part-2.md) §4. Images and computed styles are in the [evidence index](evidence/2026-11-04-fb-19-batch-catalog-and-pricing-part-2/README.md). The comparison is diagnostic: it informs the review and does not decide it.
- **Seen in a capture:** the state appears in a running-screen capture, linked here, but the script did not put the story beside it.
- **Not compared; checked against its source:** no running screen showed that state with the browser-test data, or the script could not reach it there, so it was checked against the component's source only. Where a reason is known, it is given. These stories are G-58 (record §7).

**How a decision is recorded.** An image is accepted or rejected in the pull request, row by row or as a whole. An image rejected is fixed in its story, its providers or its mocks, never by changing the component ([LIQ-010 §12.1](../LIQ-010-design-system-reproduction-architecture.md#121-each-batch)).

**Counts.** 306 stories, 612 images. 29 compared on a running screen, in 30 cases; 98 seen in a capture; and 179 checked against their source only.
