# FB-19 batch 13 part 1, reference images for review

This list holds every reference image batch 13's part 1 commits, by inventory ID ([LIQ-009](../LIQ-009-spree-component-and-token-inventory.md)), so each can be accepted or rejected, and the two earlier stories this batch's running screens compare. The batch is accepted by delegated acceptance, under the owner's delegation of 2026-11-04 ([record](2026-11-04-delegated-acceptance-and-merging.md)), at #98's final commit. That is not the owner's review.

**What to look at.** Each link opens the image beside this list, in the revision being read, and the pull request's file list shows the same images. Every image was looked at in light and dark before it was committed. One story was corrected after it was first written: the commission card's rate name, which the fixture gave as "Spirits and wine, 12%" while the seeded rate is named "Spirits and wine" (S2; [record §4.3](2026-11-10-fb-19-batch-marketplace-part-1.md#43-corrections)).

Stories use invented sellers, products, people, addresses and references. The running screens show the browser tests' own records and the sellers, products, orders and staff the batch's scripts added on the browser-test server.

**What the Running screen column means.**
- **Compared:** the story was put beside the same component on Spree's running admin dashboard, and the result is in the [verification record](2026-11-10-fb-19-batch-marketplace-part-1.md) §4. Images and computed styles are in the [evidence index](evidence/2026-11-10-fb-19-batch-marketplace-part-1/README.md). The comparison is diagnostic: it informs the review and does not decide it.
- **Seen in a capture:** the state appears in a running-screen capture, linked here, but the script did not put the story beside it. A capture of a role other than the admin names the role.
- **Not compared; checked against its source:** no running screen showed that state with the test data, or the script could not reach it there, so it was checked against the component's source only, with the reason. These stories, with the ones seen in a capture, are G-111 ([record §7](2026-11-10-fb-19-batch-marketplace-part-1.md#7-gaps)), proposed to defer to the [comparison follow-up](../LIQ-004-foundation-backlog.md#comparisons-deferred-to-later-batches) as G-101 was.

**How a decision is recorded.** An image is accepted or rejected in the pull request, row by row or as a whole. An image rejected is fixed in its story, its providers or its mocks, never by changing the component ([LIQ-010 §12.1](../LIQ-010-design-system-reproduction-architecture.md#121-each-batch)).

**Counts.** 70 stories, 140 images, for 19 components. 26 compared on a running screen; 31 seen in a capture; and 13 checked against their source only. 2 earlier stories compared (below).
