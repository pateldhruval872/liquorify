## 3. Behaviour 1.6, a library file in use

**What the criterion expects.** Criterion 1.6 asks that deleting a file a product uses be refused with Spree's message naming where it is used, and that the file stay in the library and on the product. Spree's server does refuse such a delete, with that message, when it is sent on its own: "This file is still in use (…)", with the places named, and Spree's own spec checks it.

**What the dashboard does instead.** The dashboard never sends that request. Before it deletes a file, it asks the server where the file is used, names those places in the file's panel, and asks the merchant to confirm: "Deleting “…” removes it from your library and from the 1 place using it." If the merchant confirms, it sends the delete with `detach=true`, which Spree accepts: the file leaves the library and every place that used it. The dashboard's code says this is its design ("A file in use is deletable, but the merchant confirms knowing it disappears from every place listed in the panel"). So Spree's refusal is reached only if that first question fails, which the tests do not try.

**What the tests check.** Tests 12 and 13 follow the dashboard's design, as row E of the owner's decision brief recommends:

- Test 12: the file's panel names the product that uses it, as a link; the delete warns that the file goes from the library and from the 1 place using it; cancelling changes nothing, and after a reload the file is still in the library and on the product.
- Test 13: confirming the delete sends it with `detach=true`, which the server answers 204, and after a reload the file is in neither the library nor the product.

Both pass, twice. They do not meet criterion 1.6 as it is written, and this record does not claim it. Row E asks the owner whether to correct the criterion to Spree's design, which these tests would then meet, or to keep it as written, which the dashboard cannot meet without a change to Spree's code. Until the owner answers, 1.6 is recorded as awaiting the owner, and G-57 stays open for it alone.
