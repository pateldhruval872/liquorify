# FB-19 dashboard primitives, part 1: comparison with running screens, evidence

The images and computed styles behind the [fidelity record](../../2026-10-22-fb-19-batch-dashboard-primitives-1-fidelity.md), from the diagnostic comparison script (`packages/liquorify-storybook/fidelity/compare.spec.ts`). A successful run of the script only shows that both sides could be captured. Whether each story matches its screen is the owner's judgement from these files.

**Revisions.**

| Stories | Running screens | Browser |
|---|---|---|
| [#9](https://github.com/pateldhruval872/liquorify/pull/9) at `7b1f2b8` | Spree's code at `main` `a4a1708`, which #9 does not change: the built admin dashboard, against the dashboard browser tests' own server and fixtures | Pinned image, Playwright 1.64.1, 1280 by 800 pixels |

Each case folder holds, for each theme:
- `<theme>-side-by-side.png`: the running screen on the left and the story on the right;
- `<theme>-styles.json`: the computed styles of every distinct element on both sides (`styles.screen`, `styles.story`), the elements compared, those found on one side only, and every style that differs.

"ID" is the LIQ-009 inventory ID. "Styles that differ" lists the computed properties that differ on an element found on both sides; the fidelity record §4 explains each one. The screens show the browser tests' data and the stories invented data, so text, counts and icons differ on purpose. No API key or other credential appears on these screens.
