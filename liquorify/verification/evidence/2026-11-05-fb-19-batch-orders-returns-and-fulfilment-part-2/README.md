# FB-19 batch 8, orders, returns and fulfilment, part 2: evidence

The captures, comparisons, settings checks, emails and backend results behind the [verification record](../../2026-11-05-fb-19-batch-orders-returns-and-fulfilment-part-2.md). They come from the scripts in `packages/liquorify-storybook/fidelity/` (`screens-batch-8-part-2.spec.ts` and `compare-batch-8-part-2.spec.ts`, with the data `after-sale.ts` and `staff.ts` add; `orders-settings-part-2.spec.ts`, `sd-36-canceled-fulfilment.spec.ts` and `fl-06-storefront.spec.ts`; and `order-emails.rb` with `order-emails.spec.ts`) and from Spree's own specs. A successful run of the scripts only shows that each state could be reached and captured. Whether each story matches its screen is a judgement made from the images and styles here, recorded in the verification record.

**Revisions.**

| What | Revision |
|---|---|
| Stories and scripts | The pull request the verification record names, branch `claude/project-thread-fjhoj0`. The captures, comparison, settings checks and email captures ran from the branch's working tree on `3009cc37`, and their notes name it |
| Running screens and Spree's specs | Spree's code at `3009cc37`, where the branch starts, the same as at `08bca2e2`, the revision the work item names; the pull request does not change it. The built admin dashboard against the dashboard browser tests' own Rails server and fixtures |
| The storefront | `ba6ddcd`, its `main`, built for production and run against the same browser-test server, for the shopper's order page in FL-06 and for EM-SF-03 |
| Browser | The pinned Playwright 1.64.1 image. Captures at 1280 by 960 pixels, and 390 by 844 for the one phone capture; an order page captured whole grows the window to the page's height. Comparisons at 1280 by 800, or taller where a case names it. Emails at 390 and 1280 pixels wide. Captures follow the system's light or dark setting; none stores a choice of theme |

**Image format.** Every image here is lossless WebP, converted from the PNG each script wrote. Every converted image was checked pixel for pixel against its PNG, and none differs. The reference images the visual check compares against stay PNG, in `packages/liquorify-storybook/visual/__screenshots__/`.

**Data.** The screens show the browser tests' data, their products and customers, plus the orders, fulfilments, deliveries, labels, returns, exchanges, claims, a return reason, a tax rate, roles and teammates the scripts add through the Admin API (record §1), and the settings the settings check changes and restores (record §8). Every name and reference the scripts add starts with "Fidelity", and customers and teammates use `example.com` addresses. Each capture's store is written as `<store>` in its notes. **No key, token or password is recorded,** and no capture shows one: order tokens are written `<token>` or `<order token>`, the webhook signing secret is never written, and local addresses are written `<site>` or `<storefront>`.
